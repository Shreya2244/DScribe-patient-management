# Frontend

This directory contains the React and Vite frontend for DScribe Patient Admission Management.

From this directory, run `npm install` and `npm run dev` to start the development server. Set `VITE_API_URL` to the backend API base URL ending in `/api` when using a backend other than the local default.

See the [project README](../README.md) for features, backend setup, API routes, deployment links, and data limitations.
